# MagicMirror 특허 조사 설치 파일

이 저장소는 설치 파일과 배포 안내만 공개합니다. 개발 소스 저장소와 사용자 조사 자료는 저장하지 않습니다.

[최신 배포 파일](https://github.com/nightcat01/magicmirror-patent-research-releases/releases)에서 Windows x64 Codex ZIP 또는 Claude Desktop MCPB를 내려받고 해당 릴리스의 설치 안내와 SHA-256을 확인하세요.

[운영 플랫폼](https://magicmirror-platform.vercel.app/account)에서 로그인·이용권·개인 라이선스 키를 관리합니다. 플러그인 설치만으로 이용권이 생성되지는 않습니다.

현재 베타 배포이며 ChatGPT·Codex 또는 Claude의 공식 공개 목록 등록을 의미하지 않습니다. 각 호스트의 실제 설치·조사·사람 검토·HTML 표시 시험은 별도로 진행합니다.

설치 문제는 Issues로 문의하되 비밀번호, 키, 토큰, 조사 업무 자료와 개인 파일 경로는 첨부하지 마세요.
